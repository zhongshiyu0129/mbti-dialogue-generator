你有没有过这种时刻——

> 群里那个 **INTJ**，永远在列计划，被 **ENFP** 一句「先去吃火锅吧」当场石化；

```
你：INTJ × ENFP  /  对话三行
        ↓  AI 读完对话，自动分镜
成图：两个人面对面，一个皱眉一个冒星星，气泡里是你们说的原话
```

## 📣 给 MBTI 博主

做 MBTI 梗图、情景剧的你，是不是每周都在重复：找画师 / 找素材 / 抠小人 / 排气泡 / 调尺寸，一张图磨半天？

这个工具就是为你准备的：

- **量产梗图**：选好两个人格，把段子贴进去，AI 自动分镜出图，一条笔记几分钟搞定
- **台词随便改**：气泡能直接在图上拖、缩放、改字，哪个梗不够好笑就现场改，不用整张重画

## 🎬 怎么玩

1. 打开 **[在线地址](https://mbti-dialogue-generator-whc8.onrender.com)**
2. 左边选你和对方的 MBTI（点小人就行）
3. 把对话贴进来，标清楚谁先说
4. 点 **「AI 帮我分页 & 配场景」**——它会通读对话，自动给每一页写好场景、表情、动作
5. 不满意就手动改，点生成，下载图片

> 第一次打开要等 ~50 秒，免费层在睡觉，叫醒它就好。

## 🛠️ 技术栈

- **前端**：单文件 HTML + Canvas，零构建、零框架
- **服务端**：一个 Express 小壳，负责把 Key 藏在服务端、代理转发、限流
- **画图模型**：豆包 Seedream 5.0 Flash
- **理解/编剧模型**：豆包 Seed 2.0 Mini
- **部署**：Render 免费层

> 🔒 你的 API Key 只存在服务端环境变量里，前端永远拿不到，公开也不怕泄露。
